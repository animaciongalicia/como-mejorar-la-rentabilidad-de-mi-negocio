# CLAUDE.md

## Objetivo del proyecto
Crear un blog en español sobre mejora de rentabilidad empresarial
para negocios físicos y pymes, bajo el dominio focorentabilismo.com.

## Stack
- Next.js (TypeScript, App Router)
- Tailwind CSS
- Base de datos: Supabase/Postgres
- Deploy en Vercel

## Comandos
- npm run dev    # servidor desarrollo
- npm run build  # build producción
- npm run lint   # lint

## Reglas de contenido
- Tono directo, emocional, sin humo.
- Enfocado a dueños de negocios físicos.
- Nada de tecnicismos innecesarios.
- Siempre terminar los posts con llamada a la acción.
